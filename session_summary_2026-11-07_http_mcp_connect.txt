4. FIXED "HTTP 400: stream is not readable" (DONE, COMMITTED IN 786894d)
------------------------------------------------------------------------
- `claude mcp get mcp-lab-local` failed with HTTP 400 on /messages.
- Cause: app.use(express.json()) reads the request body before the
  /messages handler runs, so the MCP SSE transport can't read it again.
- Fix in httpmcpserver/http_server.js (the /messages route):
    transport.handlePostMessage(req, res, req.body);
- The user stopped PID 16217 to restart with the fix.
